# Vela - Шапка сайта

Адаптивная верстка шапки сайта компьютерного магазина Vela.

## Технологии

- HTML5
- SCSS
- JavaScript (ES6+)
- Webpack 5
- БЭМ методология

## Установка

1. Клонируйте репозиторий:

```bash
git clone [url-репозитория]
```

2. Установите зависимости:

```bash
npm install
```

## Запуск

### Сборка для продакшена

```bash
npm run build
```

### Режим разработки

```bash
npm start
```

Откроет проект на http://localhost:3000

Создаст оптимизированную версию в папке `dist`

## Особенности

- Адаптивный дизайн (desktop и mobile версии)
- Использование БЭМ-методологии для именования классов
- Flexbox для построения сеток
- Плавные анимации при наведении
- Оптимизация для различных браузеров
- Валидная HTML5 разметка
